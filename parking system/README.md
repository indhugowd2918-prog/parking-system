# 🚗 4-Slot Parking System using Verilog

## 📌 Project Description

This project implements a simple **4-Slot Parking System using Verilog HDL**.

The system keeps track of vehicles entering and leaving a parking area.

It provides:

- Vehicle count
- Individual slot status
- Full indication
- Empty indication
- Entry detection
- Exit detection

## 🎯 Objective

The objective of this project is to design, test, and simulate a digital parking management system using Verilog HDL.

## 🔧 Technologies Used

- Verilog HDL
- VS Code
- Icarus Verilog
- GTKWave
- Git
- GitHub
